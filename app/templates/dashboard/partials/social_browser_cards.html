Авторизация через IP сервера (YouTube / TenChat)

Обход блокировок и сброса сессий: авторизация с выходного IP сервера 144.31.141.17

🛡️ Зачем нужен вход с серверного IP?

Google (YouTube) и Яндекс/SmartCaptcha (TenChat) привязывают сессию к IP-адресу. Если войти из домашнего браузера и скопировать куки на сервер в Германии, защитные алгоритмы моментально сбрасывают вход или требуют СМС. При входе через туннель они видят вас изначально с IP сервера, и сессия остаётся активной.

🍏 Способ 1: Локальный запуск на Mac (1 команда) Рекомендуется

Скрипт сам поднимет SOCKS5-туннель к серверу, откроет видимый Chromium на вашем экране, дождётся успешного входа в TenChat / YouTube и автоматически сохранит сессию в базу данных на VPS.

cd ~/Desktop/svodkapress && ./scripts/remote_login_browser.py
💡 Команда сама откроет Chromium с IP сервера. Нажмите «Войти» в аккаунт канала — скрипт автоматически сохранит сессию в базу данных на VPS.
🛠️ Способ 2: Ручная вставка через Cookie-Editor

Если у вас настроен локальный прокси в браузере (порт SOCKS5 1085), откройте сайт, авторизуйтесь, нажмите в расширении Cookie-Editor кнопку Export → Export as JSON и вставьте результат в поле нужной соцсети.
