Настройка Telegram-бота для публикации (1 минута)

1 Создайте бота у @BotFather
  1. Откройте @BotFather в Telegram.
  2. Отправьте команду /newbot, задайте имя и username.
  3. Скопируйте полученный HTTP API Token (7123456789:AA...).
2 Добавьте бота в канал
  1. Зайдите в управление каналом @svodka_press → Администраторы → Добавить администратора.
  2. Найдите созданного бота по его юзернейму и подтвердите добавление.
  3. Убедитесь, что включено разрешение «Публикация сообщений».
3 Вставьте токен и сохраните
  1. Вставьте токен в поле «Telegram Bot Token» ниже.
  2. Укажите юзернейм канала (@svodka_press).
  3. Нажмите «Проверить связь», а затем «Сохранить настройки».
