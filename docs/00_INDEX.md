## 2. Карта потоков

```text
Telegram-аккаунты / сайты
        │
        ▼
  ingestion_worker ──► raw_news
        │                  │
        │             фильтр: реклама / дайджест
        ▼                  │
   deduplicator ─────► news_clusters
        │                  │
        │             модерация: рубрика / риск
        ▼                  │
   content_worker ──► articles (MEDIA_READY)
        │                  │
        │             текст → QA → вектор → медиа
        ▼                  │
  publisher_worker ─► WordPress ─► TG / VK / OK / Dzen
```

Три воркера выполняются отдельно, с собственными очередями и локами. Панель
управления и «Лаборатория» — четвёртая часть: они не должны повторять логику
воркеров, а вызывают те же сервисы, чтобы оператор видел реальное поведение.

## 3. Основные части кода

| Папка | Ответственность |
| --- | --- |
| `app/models/` | SQLAlchemy-модели, статусы, JSONB-типы, векторы |
| `app/services/` | изолированная бизнес-логика и внешние клиенты |
| `app/workers/` | ARQ-оркестраторы: сбор, контент, публикация |
| `app/api/` | FastAPI-маршруты, аутентификация, HTMX-фрагменты, SSE |
| `app/templates/` | Jinja2-панель и сниппет для темы WordPress |
| `migrations/` | Alembic-миграции схемы |
| `scripts/` | деплой, smoke-тест БД, узкие операции по SSH |
| `tests/` | 1115 тестов без внешних сервисов |

## 4. Фактическое состояние на 2026-09-03

- Панель, PostgreSQL, Redis и распределитель моделей подняты и здоровы.
- Сбор, фильтры, MinHash-склейка, генерация, QA и локальные векторы работали на
  контрольном прогоне.
- Три воркера остановлены вручную 25 августа; конвейер выключен и не
  поднимется сам (`unless-stopped`).
- 292 статьи есть в базе, наружу опубликовано ноль: адрес WordPress настроен
  неверно и учётные данные пусты.
- Настоящий сайт `svodka.press` существует (8700 статей) и его 20 рубрик
  совпадают с каталогом в коде; текущая настройка указывает на панель, а не на
  этот сайт.
- В проде код старее локального на несколько версий. Сравнивать нужно хеши
  файлов, а не версию в `CHANGELOG.md`.

Полная таблица «работает / не работает / почему» — `PROJECT.md`, раздел 3.

## 5. Инварианты, которые нельзя ломать

- Сеть, БД и файлы — строго `async`/`await`.
- Playwright — один `BrowserPool`, не более 2 страниц, картинки и шрифты
  блокируются.
- Повтор задания не создаёт второй материал или пост: это обеспечивается
  уникальными индексами, локами и отслеживаемым JSONB `platform_statuses`.
- Текст проходит anti-slop до записи в БД.
- Размер вектора задан одной константой; векторные поля отложены по умолчанию.
- Секреты не попадают в логи, health-ответы и ошибки для пользователя.

Подробные правила работы — `CLAUDE.md` и `AGENTS.md`.
