# Дизайн панели — macOS-эстетика

## Что сделано (2026-09-03)

### Визуальная система

**Боковая панель** заменила верхний тулбар. Навигация — вертикально, каждый раздел с иконкой, активная кнопка выделена системным синим. Декоративная деталь — **window lights** (три цветные точки) вверху, единственный намёк на macOS-хром.

**Компоненты** (`.card`, `.btn`, `.field`, `.chip`) написаны в `<style>` внутри `base.html` перед Tailwind. Они задают nативную анатомию: радиус, полупрозрачность, shadow, но цвета берут из CSS-переменных — palette живёт в `:root`, а не в коде классов.

**Цвета** приведены к macOS: `--win: #1c1c1e` (тёмное окно), `--panel: #242426` (панели), `--ink/-2/-3` (текст трёх уровней), `--accent: #0a84ff` (системный синий). Плюс четыре статусных цвета (good/warn/bad/info) по палитре SF Symbols.

Старые экраны оставлены как есть: в них тысяча классов `slate-900`, `sky-300`, `emerald-950`. Вместо ручной правки **палитра Tailwind переопределена** скриптом в `<head>`: `tailwind.config = { theme: { extend: { colors: { slate: { 950: '#1c1c1e', ... }}}}`. Теперь `bg-slate-900` даёт `#242426`, а `text-sky-300` — `#7cc0ff`. Все 30 шаблонов получают nативный вид согласованно, без изменения разметки.

**Шрифт** — `-apple-system`, SF Pro. Размер базовый `13.5px` (body), `15px` (заголовки страниц), `11–12px` (лейблы, чипы). Моноширинный стек — `ui-monospace`, SF Mono.

**Focus rings** — `2px solid var(--accent)` с `outline-offset: 2px`, видны на каждом интерактивном элементе (кнопки, поля, ссылки). `prefers-reduced-motion` сбрасывает все transitions в `0.01ms`.

### Экраны

Переписаны полностью:

- **base.html** — оболочка с боковой панелью, sticky-тулбаром, футером. Навигация дублируется горизонтальной прокруткой на мобиле.
- **login.html** — центрированная карточка с window lights, самодостаточный шаблон без `extends`.
- **partials/stats.html** — обзор: четыре счётчика, две таблицы статусов, карточки воркеров.

Оставшиеся 27 шаблонов не трогались — их классы работают через переопределённую палитру.

## Что осталось

1. **Визуальная проверка остальных экранов.** Переопределение палитры безопасно (старые классы просто дают новые цвета), но без прямого просмотра нельзя гарантировать, что всё читается. Нужен сервер на порту 8010 и открытая база.

2. **Мелкие несоответствия.** Часть разметки пишет цвет напрямую (`bg-slate-100`, `text-slate-900`), что ломает дизайн: `slate-100` теперь почти белый, а был бледно-серым. Нужен grep-аудит и точечная замена на компонентные классы.

3. **Модальные окна** (`article_preview.html`, `article_edit.html`, `article_journal.html`) не видел — они рендерятся HTMX. Вероятно, нужна оверлея `.backdrop` с `rgba(0,0,0,0.72)` и карточка поверх.

4. **Таблицы.** `articles_block.html` пишет `<table>` старой палитрой (`border-slate-800`, `bg-slate-900/40`). Нужен компонент `.table` с macOS-правилами: hairline-разделители между строками, hover-подсветка, tabular-nums для дат.

5. **Формы.** Селекторы и поля фильтров (`articles.html`, `settings.html`) сейчас `border-slate-700 bg-slate-900`. Должны использовать `.field`, но это требует рефакторинга разметки.

6. **Лаборатория** (`lab.html`, 600+ строк) — самый тяжёлый экран. Там вложенные блоки (`lab_wipe.html`, `lab_runs.html`, `lab_run.html`), подтверждения, логи прогонов. Без запуска не проверить.
