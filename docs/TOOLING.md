# Инструменты: скилы и MCP-серверы

Установлено глобально 2026-09-02, видно во всех проектах. Резервная копия
прежнего набора скилов: `~/.claude/backups/skills-before-install-20260902-185421`.

**Скилы — библиотека, а не обязанность.** Скил вызывается, когда задача реально
совпала с его назначением. Вслух вызов не объявляется. Никакой скил не отменяет
цикл проверок из `CLAUDE.md`: `[x]` без пройденных `ruff`, `mypy`, `pytest` —
ложь в трекере, чей бы совет ни был.

**Не править скилы на месте.** Они склонированы из upstream, локальная правка
потеряется при обновлении. Нужно проектное поведение — писать в `CLAUDE.md`.

## Скилы по назначению

### Методология (из `juliusbrussee/caveman`) — подходит этому проекту

Встраивается в обязательный цикл верификации:

| Скил | Назначение |
| --- | --- |
| `investigate-first` | Собрать улики до правки, ранжировать версии по доказательности. Основной инструмент при разборе поломок на проде |
| `surgical-patch` | Править на самом узком слое, который владеет поломкой; не трогать соседнее |
| `verify-and-stop` | Доказать, что сделанное соответствует критериям, и остановиться, не расширяя объём |
| `safe-refactor` | Перестройка кода с сохранением поведения, проверки до и после |
| `caveman-explore`, `caveman-discover` | Разведка по незнакомой части кода |
| `caveman-review`, `caveman-evidence-review` | Обзор по фактам, а не по впечатлению |
| `lean-build`, `migration`, `caveman-commit` | Сборка, миграции, коммиты |

Прежний набор `caveman-*` (`diagnose`, `verify`, `prevent`, `run`, `save`,
`kill`, `think`, `code`, `research`, `teach`, `advise`, `conclusion`, `loop`,
`cheat`, `portability`) остался на месте и по-прежнему применим — см. `CLAUDE.md`.

### Внешний вид сайта и панели

| Скил | Назначение |
| --- | --- |
| `frontend-design` | Официальный от Anthropic. Осмысленная типографика, палитра, отказ от шаблонных решений. Основа при работе над видом новостного сайта и панели |
| `brandkit`, `minimalist-skill`, `redesign-skill` | Палитры, айдентика, переработка существующего вида |
| `modern-web-design` | Современные приёмы вёрстки |

### Ограниченно применимо — знать границы

**`taste-skill`** (13 скилов) прямо говорит о себе: «не для панелей, не для
таблиц данных, не для многошагового интерфейса продукта». Панель управления —
ровно это. Брать оттуда знание про палитры, типографику и контраст; готовые
решения для дашборда — нет.

**`claudedesignskills`** (23 скила: Three.js, WebGL, GSAP, Lottie, Rive,
Babylon, R3F, Blender) предполагают React, node-сборку и `node_modules`. Здесь
стек — Jinja2 + HTMX + Tailwind через CDN, **без билд-шага, и так задумано**.
Применимы как справочник по анимации и приёмам, не как готовые компоненты.

### Не применять в этом проекте

| Скил | Причина |
| --- | --- |
| `caveman-style` | Предписывает речь пещерника с «БРО» и эмодзи, в метаданных `autoinvoke: true`. Стиль ответов задаёт `CLAUDE.md`: по-русски, спокойно, по делу |
| `caveman` (новый, из `juliusbrussee`) | Сжатая речь пещерника как стиль всей сессии. Вызывается только явно (`/caveman`), сам не включается — но в этом проекте не используется |
| `caveman-desktop` | Про systemd-автозапуск, OBS и видео. К проекту отношения не имеет |

Речевые хуки плагина `caveman` (`SessionStart`, `UserPromptSubmit`, которые
включают режим автоматически) **намеренно не установлены**: они бы переопределяли
стиль ответов глобально, во всех проектах, вопреки правилам этого. Методологические
скилы того же репозитория поставлены и полезны — ценность там в методе, а не в речи.

## Что где лежит

- Скилы: `~/.claude/skills/<имя>/SKILL.md` — 81 штука.
- Настройки MCP: `~/.claude.json`, раздел `mcpServers`, область user.
- Резервные копии: `~/.claude/backups/`.

Проверить целостность набора:

```bash
cd ~/.claude/skills && for d in */; do [ -f "$d/SKILL.md" ] || echo "BROKEN: $d"; done; echo "total: $(ls -1d */ | wc -l)"
```
